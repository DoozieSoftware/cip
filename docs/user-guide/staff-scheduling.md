# Planning and scheduling trips (staff)

> **Where to find it:** sidebar **Trips**
> (`/operations/textile-collections/schedule`)

## Ground rules

- One trip = **one service zone**. Requests from two zones cannot share a trip.
- Only **approved pickup** requests (or missed ones being redone) can be scheduled.
- **Drop-off bookings must never enter a trip.**
- A trip below the 2-bag / 4-kg minimum is blocked.

## Step by step

1. Open the **Schedule** desk.
2. Find the zone section. Each row shows the `DLN-` reference, citizen, address, and estimated bags and kg.
3. Tick the requests for this trip. A capacity panel totals the load and checks it against the zone’s vehicle limits:
   - Too many bags, kg, or stops → a red blocker explains what to remove or split.
   - Near a limit → an amber warning asks for a careful look.
   - Below the minimum → blocked; remove stops or move the citizen to drop-off.
4. Set the **collection date** and time window.
5. With 2 or more stops, a **suggested stop order** appears — the shortest driving sequence, nearest first. Click **Apply** to reorder the on-screen manifest. This reorders only; it schedules nothing by itself.
6. Fill in driver or team, vehicle, and any instructions for the crew.
7. Press **Schedule trip**. The trip gets a **`DRL-`** reference and each request becomes *scheduled* with the date and window.

## Changing a scheduled trip

- Reorder stops any time before field work starts.
- To move a request to another date, reschedule it — the old trip assignment is removed automatically and both dates stay in the audit history.
- Once the driver has started the trip, changes need an authorised override.
