# Citizen use-case image fixtures

These images are local-only fixtures for manually testing the citizen report flow. They are not seeded into production and are not presented as real citizen evidence.

The files were located through web image search and downloaded from Wikimedia Commons. The set uses wide/contextual views rather than close-up crops. It prioritizes Bengaluru; the electricity fixture uses a Delhi street scene and the dead-animal fixture uses another India-specific roadside scene because suitable Bengaluru examples with clear reuse terms were not available. Keep the source and licence information with the files if they are moved or reused.
